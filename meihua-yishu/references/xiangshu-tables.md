## 6. 应期算法（p221–p223）

1. 生体卦气之日应吉，克体卦气之日应凶。
2. 生体之卦的位置定快慢：用卦生体＝即成；互卦生体＝渐成；变卦生体＝稍迟。
3. 有生有克＝有阻节；阻力天数按克体之卦先天数（乾1 兑2 离3 震4 巽5 坎6 艮7 坤8）。
4. 吉事：有克体无生体→不成；无克体→必成。凶事：有生体→有救；无生体→必凶。

## 7. 十八类占（p164–p178，一句话判法）

| 所问 | 判法 |
|---|---|
| 天时 | 不分体用，数卦中何卦多：离晴、坎雨、坤阴、乾晴、震雷、巽风、艮止（久雨必晴）、兑不雨亦阴；纯离夏旱、纯坎冬雪 |
| 人事 | 用克体凶、体克用吉、用生体益、体生用耗、比和吉利 |
| 家宅 | 体克用宅吉；用克体宅凶；体生用耗散防盗；用生体进益 |
| 屋舍 | 体克用居吉；体生用资财衰；用生体门户兴隆 |
| 婚姻 | 用生体易成且有得；体生用难成；用克体不成，成亦有害；比和吉利。相貌取象：乾端正而长、坎黑而妒、艮黄多巧、震美貌难犯、巽发稀丑贪、离短赤性不常、坤丑大腹黄、兑高长语悦白 |
| 生产 | 体为母、用为子；俱宜旺宜生；体克用不利子、用克体不利母；用生体易于母、体生用易于子；阳卦阳爻多生男 |
| 饮食 | 用生体食丰；用克体必无；有坎必有酒、有兑必有食；席上何人看互卦 |
| 求谋 | 用生体不谋而成；体生用多谋少遂；用克体不成且有害 |
| 求名 | 用生体名易成；体生用因名有丧；在任占最忌克体；成名日看生体卦气、任职方看变卦方位 |
| 求财 | 体克用有财、用克体无财、体生用耗财、用生体进财；得财日看生体卦气、破财日看克体卦气 |
| 交易 | 用生体即成且有财；体生用难成或有失 |
| 出行 | 体克用可行；乾震多主动、坤艮多不动；巽宜水路、离宜陆路；坎防失脱、兑主纷争 |
| 行人 | 用生体即归；体克用归迟；用衰受克在外有灾；震多不宁、艮多有阻 |
| 谒见 | 用生体可见且有得；用克体不见；体生用见之无益 |
| 失物 | 用生体易寻、用克体不可寻；比和物未失（一时想不起）；所在看变卦方位 |
| 疾病 | 体为病人、用为病症；体克用勿药有喜、用克体虽药无功；体受克而旺犹可救、衰则无生理；药性看生体卦：离宜热药、坎宜冷药、艮宜温补、乾兑宜凉药 |
| 官讼 | 体克用可胜、用克体不利；体生用耗财、用生体得理；生体卦定解脱日 |
| 坟墓 | 体克用吉、用克体凶；卦象定坟形与后人兴衰 |

## 9. 六处易错

1. 用公历数字起卦（须农历）。
2. 只套体用表，忘了"理胜处断之"。
3. 类象当答案（兑可为少女／口／羊／破损物，靠外应与事理定）。
4. 不辨真假生克，量级判反。
5. 多爻变仍改体用（应守上体下用）。
6. 六爻皆静仍强分体用（应只以本卦＋互卦断）。
