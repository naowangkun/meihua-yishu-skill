# 测字（相字）体系摘要

出典：郑同《梅花易数讲义》卷四至卷六（p278 前后–p322），主体为《测字秘牒》一系。约占原书三分之一篇幅。

## 与卦占的关系

同源不同法：都走"取象—得数—以理断事"，但卦占把"数"变成卦，测字把"字"直接当卦看。卷六"测字十法"里有一法就叫"观梅"，是两套体系最直接的接点（见字之形、之缺、之偏旁即起象）。

**边界**：用户问的是"这事吉凶"并且可用时间／数字起卦时，走卦占；用户专门要"测一个字""看这个字/名字/签名"，才走测字。不要用测字结论去补卦占结论。

## 一、测字十法（卷六·测字秘牒）

| 法 | 做法 |
|---|---|
| 装头 | 于字上加偏旁／笔画，看加后成何字，以所成之字取象 |
| 接脚 | 于字下加笔画成字，取象同上 |
| 穿心 | 字中插入笔画成新字 |
| 包笼 | 以笔画包裹原字，看包裹后形态 |
| 破解 | 拆开原字为几个部件，各部件取象 |
| 添笔 | 增笔看增后字义 |
| 减笔 | 减笔看减后字义（常用于断"缺什么"） |
| 对关 | 取相对的两字／两部件对看（吉凶、内外、迟速） |
| 摘字 | 从一句话或一段文中摘取关键字来测 |
| 观梅 | 见字之形、之缺、之偏旁即起象，与梅花易数"见物起卦"同法 |

## 二、卷四总论要点

- 指迷赋、玄黄克应歌：测字总纲与"玄黄"（天地之色）取应原则。
- 花押赋、探玄赋：从签名花押、笔画气势断人（笔势刚柔、收笔向背）。
- 字画经验、字体诗诀、画有阴阳、八卦断、相字心易、笔法筌蹄：以笔画、结构、书写时的笔墨状态取象。
- 六神笔法、六神主事、笔画犯煞：把六神（青龙、朱雀、勾陈、螣蛇、白虎、玄武）配到笔画上断吉凶。

## 三、卷五技法

五行全备、六神形式、八卦辨、七言作用歌、比例歌、西江月（断语口诀）；古人相字、拆字纪事（案例）；断富贵贫贱要诀、五行四时旺相休囚、天干地支属五行、论八卦性情、八卦取象、六十甲子歌、浑天甲子定局、后天时方（基础表）；八反格、四言独步、五言作用歌、别理论、六言剖断歌、格物章、物理论、五行六神辨别论、金声章（断法与格物）。

## 四、实战取用顺序（建议）

1. 定所测之字：单字、姓名、招牌、签名，取用户实际所写（不是心里想的那个字）。
2. 先看字形结构（上下、左右、包围、缺笔、多笔）→ 用"破解／添笔／减笔"取象。
3. 再看书写状态（笔势、墨色、快慢、字体）→ 六神笔法与"字画经验"。
4. 再看外应（写字时的天时、声音、旁人言语）→ 与卦占的十应同法。
5. 结论落点：事之成败、人物身份、时间远近（以字的"内外""上下"定迟速）。
6. 若用户其实要问"事之吉凶"，回到卦占，用时间／报数／字数为数起卦，测字只作补充。

## 五、纪律

测字最易滑向"随口联想"。约束三条：一是每个结论必须指出依据的是哪一笔、哪一部件、哪条口诀；二是同一字不给两套互斥结论；三是无法从字形取象时，如实说"此字无可取之象"，改走卦占，不要编。
