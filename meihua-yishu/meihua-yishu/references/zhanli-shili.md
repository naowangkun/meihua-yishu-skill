# 经典占例的推理链（校准用）

出典：郑同《梅花易数讲义》卷一占例（p086–p112）。页码为 399 页扫描版 PDF 页。

用途：第一次断卦前读这篇，校准"该断多细、该断多重"。每个例都给出**算式 → 卦象 → 体用 → 加权 → 取象落点 → 应期**的完整链条。

## 例 1 观梅占（书名的由来，p086–p090）

- 算式：辰年5＋十二月12＋十七日17＝34；34÷8 余 2＝兑为上卦；34＋申时9＝43，43÷8 余 3＝离为下卦；43÷6 余 1＝初爻动。
- 卦象：**泽火革**，初爻动 → 变 **泽山咸**；互见乾、巽。
- 体用：兑金为体（少女），离火为用克体；互中巽木生离火 → 克体之气更盛；巽为股，又被乾金兑金克 → 伤在股；初爻变艮土生兑金 → 伤而不凶。
- 落点：少女、股、次日。
- 要点：**用克体＋互生用＝克体势盛**；变卦生体定"有救"。

## 例 2 牡丹占（p091–p093）

- 算式：巳年6＋三月3＋十六日16＝25；25÷8 余 1＝乾为上；25＋卯时4＝29，29÷8 余 5＝巽为下；29÷6 余 5＝五爻动。
- 卦象：**天风姤**，五爻动 → 变 **火风鼎**；互见重乾。
- 体用：巽木为体，乾金克之，互又见重乾 → 三金克一木，卦中无生意 → 花必毁；乾为马 → 马践；变卦上离为日、为明 → 午时。
- 要点：**同五行之卦越多，克体之势越绝对**；应期可取变卦之象（离＝午时）。

## 例 3 邻夜扣门借物占（p094–p095）

- 算式：一声＝乾为上，五声＝巽为下 → **天风姤**；1＋5＋酉时10＝16，16÷6 余 4＝四爻动 → 变巽；互见重乾。
- 卦象：三乾金、二巽木 → 金木之物；乾金短、巽木长 → 斧。
- 断法关键：其子断"锄"，邵雍改断"斧"，理由是"以理推之，夕晚安用锄？"——**卦只给候选集（金短木长：斧也可、锄也可），定型靠常识与情境**。
- 原文："起数又须明理……推数不推理，是不得也。"

## 例 4 今日动静如何（p096–p097）

- 六字按字占（平分三三）起卦，得 **地风升**，初爻动。
- 常规：用卦巽木克体卦坤土 → 主无饮食。
- 修正：问句"如何"二字带口 → 兑为口、重兑之义 → 有人相请，但酒食不丰。
- 要点：这是"卦断遗论"第一类例外——**外应可推翻体用结论**。

## 例 5 西林寺碑额占（p098–p100）

- 以"西林"二字笔画起卦，得 **山地剥**。
- 常规：体用互变皆土，比和 → 应断吉。
- 修正：寺为纯阳人居所，卦却群阴剥阳 → 断不吉，后有阴人之祸。
- 要点：**理胜处断之**；原文"此理甚明，不必拘体用也"（p158）。

## 例 6 少年有喜色占（p101–p104）

- 见少年有喜色，端法后天起卦，得 **山火贲**。
- 用不生体，但互、变皆生体，且《贲》六五爻辞"束帛戋戋，吝，终吉" → 断有婚聘之喜，十七日内应验。
- 要点：**外应（色）定性＋爻辞佐证＋互变定成败**，三者同向则断得重。

## 例 7 牛哀鸣占（p105–p106）

- 得 **地水师**：用不生体，互变俱克体，且《师》六三"师或舆尸，凶" → 大凶，牛二十日内遭屠。
- 要点：与例 6 成对读——**哀音／喜色的外应方向与卦象同向时，吉凶加倍；逆向时以卦象为主**。

## 例 8 枯枝坠地占（p107）

- 见枯枝自坠，以枯木之数起卦，断某日当有伐木之应。
- 要点：静物异动也是"动"，可占；取象在"枯"（死木）与"坠"（下）。

## 十四则占例的其余六则（p108–p112）

风觉鸟占、听声音占、形物占、验色占等，把起卦入口从时间数字扩展到**风、声、形、色**四类外应。方法仍是"以数起卦、以象定事"，但作者反复强调：外应本身就是信息的一部分，不必全靠卦。

## 从这些例子里抽出来的四条校准线

1. 先算结构（体用互变），再算权重（党数、旺衰、真生真克），最后才取象落点。
2. 一个卦里同时出现多种类象时，用外应和事理排除，不留两个答案。
3. 结局轻重看变卦，过程看互卦，当下应验看克应。
4. 应期宁可给窗口（日／旬／月），不给精确到时辰的假精确，除非变卦之象直接指时（如离＝午时）。
