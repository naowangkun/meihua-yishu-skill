# 梅花易数占断

以《梅花易数》原书规则为准，不掺流行口诀。判法可回溯到卷次与页码，页码为该书 399 页扫描版 PDF 页（PDF 页 ≈ 书页 + 55）。

## 一、三条硬规矩（先立规矩再起卦）

1. **不动不占，不因事不占**（p086）。没有具体问事、没有异象就不起卦；用户只说"随便算算"时，先问清"所问何事"，一事一占。
2. **年月日一律用农历**（p072）。用户给公历时间，必须先换算农历干支（查万年历或联网核对）；换算不了就改走报数、字占、物数，绝不可拿公历数字直接起卦。时辰用十二时辰序数（子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12）。
3. **理在数先**（p158）。卦只给候选集，落到什么人、什么物、什么部位、什么时候，必须靠事理与当下外应定型。只套卦名不断事，等于没断。

## 二、流程

### 第 1 步：定问事与起卦入口

先确认**所问何事**与**当下所见所闻（外应）**。按场景取数：

| 场景 | 取数 |
|---|---|
| 有准确农历时间 | 年支数＋农历月＋农历日＝基数，再加时辰数 |
| 用户报数 | 所报之数（多位数可取各位和） |
| 见字／写字 | 一字取左（上）右（下）笔画；二字取前后字；三字取首字；四、五字取前二字和；六、七字取前三字和；八字以上平分（少为阳上、多为阴下） |
| 闻声 | 声音次数（敲门、鸣叫、器物响） |
| 见物 | 件数、尺寸（尺数／寸数） |
| 见异象（后天端法） | 以所见之象（人、物、色、方位）取卦，加时数定动爻 |

笔画以书写者实际所用字体为准（写简体数简体），不必强转繁体。

### 第 2 步：排卦（用脚本，别手算）

```bash
python scripts/paigua.py --num <基数> --shichen <1-12> [--season 春|夏|秋|冬|四季月]
python scripts/paigua.py --shang <上卦先天数1-8> --xia <下卦先天数1-8> --dong <动爻1-6>
python scripts/paigua.py ... --multi 2 5        # 多爻动，守"上体下用"
python scripts/paigua.py ... --json             # 机器可读
```

脚本按原书法则输出：卦以八除（整除取 8）、爻以六除（整除取 6）、互卦（2·3·4 下互、3·4·5 上互，分体互用互）、变卦、体用、五行生克、党数、旺衰、应期提示。**结构不要自己重算**，断语必须自己写——脚本只给骨架。

### 第 3 步：定体用与生克

体＝自己／求测人，用＝所问之事，互＝过程，变＝结局，克应＝当下信号；权重"用最紧、互次之、变又次之"（p222）。动者为用、静者为体；多爻变时仍上卦为体、下卦为用；六爻皆静则不分体用，只以本卦＋互卦断。

五条判词：体克用吉、用克体凶、体生用耗失、用生体进益、比和顺遂。
加减三条：体宜受生不宜受克；体党多则体盛、用党多则体衰；用吉变凶者先吉后凶。

### 第 4 步：过三道筛子（决定准不准）

1. **卦气旺衰**（p160、p226）：春震巽旺、夏离旺、秋乾兑旺、冬坎旺、四季月坤艮旺；旺相逢克犹可支撑，衰囚受克基本必败。
2. **真生真克**（p223–225）：炉火窑灶真火才克金，红紫、日光、灯烛只是火之形色；快刀巨斧真金才克木，钗箔锡器不能；真水才克火。"克我的东西是真克还是只是像"，定吉凶量级。
3. **卦断遗论四例外**（p158）：比和而事理相反者从理；用克体而外应显有其事者从外应；用不生体而互变生体者吉；用不克体而互变俱克者凶。

### 第 5 步：取外应定性

三要（眼观形色、耳听声音、心断其理）＋十应（天时、地理、人事、时令、方卦、动物、静物、言语、声音、五色、写字拆字）。外应与卦象同向则加重，相悖则以卦为主、以外应定具体所指。类象多义（兑可为少女／口／羊／破损物），取哪个由事理与外应决定。

### 第 6 步：定应期

生体卦气之日应吉、克体卦气之日应凶；用卦生体即成、互卦生体渐成、变卦生体稍迟；有生有克则有阻节，阻力天数按克体之卦先天数（乾1 兑2 离3 震4 巽5 坎6 艮7 坤8）。

### 第 7 步：出结论

见"输出格式"。

## 三、按类断（十八占）

天时不看体用，只数卦多；其余十七类按 体＝己／用＝事 走五判词，再按类补规则（失物看变卦方位、疾病看生体卦定药性、求财看生体卦气定得财日等）。全表见 `references/xiangshu-tables.md`。

测字（相字）另成体系，见 `references/cezi.md`，与卦占同源不同法，不要混用。

## 四、输出格式（固定五段，不写套话）

1. **起卦**：所问何事、取数依据、基数与时辰、算式（上卦＝数÷8取余、下卦＝(数＋时)÷8、动爻＝(数＋时)÷6）。
2. **卦象**：本卦、互卦（标体互／用互）、变卦、体用定位与五行。
3. **断据**：五判词结论 → 党数 → 卦气旺衰 → 真生真克 → 卦断遗论是否触发 → 外应校正。逐条说清哪条把结论推向吉或凶。
4. **结论**：一句话主断（成／不成、吉／凶、有救／无救），落到具体人、物、部位、方位。
5. **应期与可验证点**：时间窗口（日／旬／月）＋一个可当场核对的标志（如"当日有口舌、来自西方"）＋**失手条件**（出现什么现象就说明此卦断错，如"若三日内无任何饮食之应，则此占不验"）。

纪律：不写"可能、也许、因人而异"式两头堵；同一卦不给互相矛盾的两套结论；先判词后解释。传统术数推演，仅供参照，不替代医疗、法律、投资的专业判断。

## 五、资源

- `scripts/paigua.py`：排卦器（本卦／互卦／变卦／体用／生克／应期提示）。已用书中观梅占（34＋申9→泽火革，初爻动，互乾巽，变泽山咸）、牡丹占（25＋卯4→天风姤，五爻动，变火风鼎）、地山谦例（24＋午7→初爻动变地火明夷）验证一致。
- `references/xiangshu-tables.md`：先天数、八卦类象、生体克体兆象、卦气旺衰、十八占、失物方位、真生真克速判。断具体事时读。
- `references/zhanli-shili.md`：书中经典占例的完整起卦与推理链，校准"该断多细、该断多重"。第一次断卦前读。
- `references/cezi.md`：卷四至卷六测字体系（十法、六神笔法、取格），用户问测字时读。
